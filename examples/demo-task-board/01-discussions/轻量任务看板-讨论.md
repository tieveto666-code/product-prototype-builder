# 轻量任务看板 · 需求讨论

> 示例项目，用于展示 `product-prototype-builder` 的第一阶段产出格式。

## 原始想法

做一个适合小团队或个人使用的轻量任务看板，比 Jira 简单，比 Todo 列表更适合协作跟进。

## 目标用户与使用场景

- **目标用户**：5 人以内的小团队、独立开发者、产品/设计小组
- **使用场景**：每日站会前整理任务、按状态跟踪进度、快速查看本周完成情况

## 用户痛点与产品价值

| 痛点 | 产品价值 |
|------|----------|
| 重型项目管理工具学习成本高 | 开箱即用的三列看板 |
| 纯 Todo 难以体现流程状态 | 待办 / 进行中 / 已完成清晰流转 |
| 工具切换成本高 | 单页完成主要操作 |

## 核心使用流程

1. 打开看板，查看三列任务分布
2. 新建任务，填写标题、优先级、负责人
3. 通过拖拽或按钮将任务在不同列间移动
4. 搜索或按优先级筛选任务
5. 切换到统计页查看任务分布

## 功能需求

- 看板三列：待办、进行中、已完成
- 任务 CRUD：新增、编辑、删除（删除需确认）
- 状态流转：拖拽或快捷按钮移动任务
- 搜索：按标题关键字过滤
- 筛选：按优先级（高/中/低）
- 统计视图：各状态任务数量与优先级分布
- 数据持久化：浏览器 `localStorage` 模拟

## 数据对象与关键字段

**Task**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| title | string | 任务标题，必填 |
| priority | enum | high / medium / low |
| assignee | string | 负责人 |
| status | enum | todo / doing / done |
| createdAt | string | 创建时间 |

## 用户角色与权限

- 单用户模式，无需登录（原型阶段）
- 所有操作本地模拟，无权限隔离

## 业务规则

- 任务标题不能为空，最长 80 字
- 删除任务需二次确认
- 状态变更后立即更新列计数与统计

## 交互预期

- 左侧导航：看板、统计
- 顶部工具栏：搜索框、优先级筛选、新建任务按钮
- 看板卡片：点击可查看详情；支持拖拽到其它列
- 新建/编辑：弹窗表单，含校验与错误提示

## 视觉与风格偏好

- 简洁后台风格，主色 `#2563EB`
- 卡片式看板，留白充足
- 优先级用颜色标签区分（红/橙/灰）

## 约束条件与非目标范围

**约束：**

- 单文件 HTML 原型
- 无后端、无真实协作

**非目标：**

- 多人实时协作
- 子任务、评论、附件
- 移动端深度适配（保证桌面与窄屏不崩坏即可）
