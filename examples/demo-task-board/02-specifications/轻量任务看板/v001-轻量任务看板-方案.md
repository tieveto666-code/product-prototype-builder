# 轻量任务看板 产品需求文档 v001

## 1. 需求目标

提供一个面向小团队的轻量任务看板原型，支持任务创建、状态流转、搜索筛选和基础统计，用于验证「简单协作跟进」的产品体验。

## 2. 背景与用户痛点

小团队常在大而全的项目管理工具和过于简单的 Todo 工具之间摇摆。前者配置重，后者难以表达流程。本产品以三列看板为核心，降低使用门槛，同时保留必要的状态管理。

## 3. 用户角色与核心场景

| 角色 | 场景 |
|------|------|
| 团队成员 | 每日查看自己负责的任务进度 |
| 小组负责人 | 站会前快速浏览各列任务分布 |

## 4. 需求范围

- 看板视图（三列）
- 统计视图
- 任务新增、编辑、删除
- 拖拽/按钮状态流转
- 搜索与优先级筛选
- localStorage 持久化
- Toast 操作反馈

## 5. 非目标范围

- 登录注册、权限体系
- 多人协作、评论、附件
- 后端 API、真实数据库

## 6. 产品架构

```text
轻量任务看板
├── 看板页
│   ├── 顶部工具栏（搜索 / 筛选 / 新建）
│   └── 三列看板（待办 / 进行中 / 已完成）
├── 统计页
│   ├── 状态数量卡片
│   └── 优先级分布图
└── 通用组件
    ├── 任务表单弹窗
    ├── 删除确认弹窗
    └── Toast 提示
```

## 7. 使用流程

1. 用户进入看板页，查看默认示例任务
2. 点击「新建任务」，填写表单并保存
3. 拖拽卡片到其它列，或通过卡片菜单移动状态
4. 使用搜索框或优先级筛选缩小结果
5. 切换到统计页查看任务分布
6. 刷新页面后，数据仍保留在 localStorage

## 8. 产品风格与功能布局

- **布局**：左侧 220px 导航 + 右侧内容区（内边距 24px）
- **主色**：`#2563EB`；背景 `#F8FAFC`
- **组件**：圆角卡片、统一按钮、标签式优先级

## 9. 功能明细与交互逻辑

### 9.1 看板页

- 三列标题显示列名与任务数量
- 卡片展示：标题、优先级标签、负责人
- 卡片点击：打开详情/编辑弹窗
- 卡片拖拽：释放到目标列后更新状态
- 卡片菜单：提供「移至进行中」「移至已完成」等快捷操作

### 9.2 新建/编辑任务

- 字段：标题（必填）、优先级（必选）、负责人（选填）
- 校验失败：字段下方红色提示，禁止提交
- 提交成功：关闭弹窗 + Toast + 列表刷新

### 9.3 删除任务

- 点击删除 → 确认弹窗 → 确认后移除 + Toast

### 9.4 搜索与筛选

- 搜索：实时过滤标题包含关键字的任务
- 筛选：全部 / 高 / 中 / 低，筛选状态在工具栏可见

### 9.5 统计页

- 三个指标卡：待办数、进行中数、已完成数
- SVG 柱状图：各优先级任务数量
- 切换回看板页时保留筛选条件（可选）

## 11. 状态、规则与异常处理

| 场景 | 处理 |
|------|------|
| 标题为空 | 表单校验阻止提交 |
| 某列为空 | 展示空状态文案 |
| 删除任务 | 二次确认 |
| localStorage 不可用 | 降级为内存数据并 Toast 提示 |

## 12. 原型页面清单

| 页面/模块 | 说明 |
|-----------|------|
| 看板页 | 主界面 |
| 统计页 | 数据概览 |
| 任务表单弹窗 | 新增/编辑 |
| 删除确认弹窗 | 危险操作确认 |

## 13. 验收标准

- [ ] 导航可在看板/统计间切换，选中态清晰
- [ ] 新建、编辑、删除任务均可完成且有反馈
- [ ] 拖拽或快捷操作可改变任务状态
- [ ] 搜索与筛选生效
- [ ] 刷新后数据保留
- [ ] 布局间距合理，无明显重叠
